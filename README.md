├── index.html          … LP本体

│   └── raw/               … 元画像（未圧縮）のバックアップ

## 2. CTAリンクの差し替え方法

`js/main.js` 冒頭の `CONFIG` オブジェクトを書き換えるだけで、
電話・LINE・予約フォームへのリンクがサイト全体に反映されます。

```js
var CONFIG = {
  TEL: "0566-77-7772",
  LINE_URL: "https://line.me/ti/p/@luy1644d",
  FORM_URL: "https://lin.ee/RUv8use", // 予約ボタンの遷移先（現在はLINE予約）
};
```

## 3. CV計測について

- `data-cta` 属性のついた要素をクリックすると `dataLayer.push({event:"cta_click", ...})` が発火します（GTM未導入でも動作、GTM導入後は自動でタグに拾わせられます）。
- スクロール到達率（25/50/75/100%）も同様に `dataLayer.push({event:"scroll_depth", ...})` されます。
- GTMコンテナIDが決まったら `index.html` の `<!-- GTM PLACEHOLDER -->` 直後に公式スニペットを追加してください（IDが不明なため未設置）。

## 7. CTA設計

基本CTA文言は「無料体験に予約する」に統一。遷移先はLINE予約（`https://lin.ee/RUv8use`）。配置箇所：

- ヘッダー（PC版のみ）
- ファーストビュー
- コース紹介の各カード＋コース紹介直後の体験/カウンセリング案内ボックス
- **お客様の声セクション直後**（根拠提示の直後にCTAを置くと単独でCVR+68%という報告あり／`LP作成マーケティング重要項目リサーチ.pdf` p.8）
- **FAQセクション直後**（不安解消の直後に離脱させず予約導線へ）
- ページ最下部（最終CTA）
- スマートフォン：画面下部固定バー（電話／LINE／予約の3択）

FVの直下には「続きがあることを示唆する」バウンドするスクロール矢印（`.scroll-cue`）を設置し、ファーストビューが"終わったように見える"状態（false bottom）を避けています。

## 8. 次にABテストすべき項目 3つ

`LP作成マーケティング重要項目リサーチ.pdf`（2026年8月22日時点、CXL/Think with Google等の一次情報に基づく）の指摘に沿い、
**「影響の大きい要素（見出し・価値提案・構成）から検証し、ボタンの色のような細部は後回しにする」**という優先順位で選定。
検証は最低2週間・十分なサンプルサイズを確保し、初動3〜4日の"疑似有意"で判断を早期停止しないこと（同資料 p.11）。

1. **ファーストビューの見出し**：現行の「人生最後のダイエットしませんか？」（率直な意思確認型）と、「頑張っているのに変わらないのは、やり方が合っていないだけかもしれません。」（原因の言い換え訴求）を比較し、体験予約率への影響を検証する。
2. **体験訴求の出し方**：「体験0円キャンペーン」を最終CTA直前にも大きく再掲するパターンと、現行のように料金セクション内にとどめるパターンを比較する（不安を煽らず自然に後押しできるか）。
3. **コース紹介の並び順**：現行は「3ヶ月集中→ボディメイク→健康改善」の順（集中コースを最優先訴求）。健康改善コース（心理的ハードルが低い月額プラン）を先頭に置くパターンと比較し、どちらがコース詳細への熟読・CTAクリックにつながるかを検証する。

## 9. なぜこのLP構成なら体験予約率が上がると考えたか

1. **「私のことだ」と思わせる悩み描写**：お腹・二の腕・姿勢・股関節など、40〜50代女性が読んだ瞬間に自分ごと化できる具体的な悩みを冒頭で提示し、以降のコンテンツを読み進める動機を作っている。
2. **24時間ジム・自己流を否定しない論理構成**：「今まで頑張ってきたこと」を否定せず「やり方が合っていなかっただけ」と再解釈させることで、心理的な防御（「自分の努力不足を指摘された」という反発）を避けつつ、パーソナル併用の必要性を自然に納得させている。
3. **回数券ではなく目的別プログラムとして提示**：「24回券」ではなく「3ヶ月短期集中ダイエットコース」として見せることで、購入対象を「トレーニング回数」から「その先にある身体の変化」に転換し、価格の心理的ハードルよりも成果イメージを先に想起させている。
4. **実績と根拠に基づく安心設計**：元RIZAP実績トレーナー・生理学/解剖学/栄養学に基づく指導・完全個室・実在するお客様の声など、"追い込み系"ではなく"根拠のある伴走型"という差別化ポジションを一貫して裏付けている。
5. **不安解消と摩擦の最小化**：運動が苦手／食事制限が厳しそう／他の客と会う／持ち物が分からないといった、初めてのパーソナル利用者が体験予約直前に感じる不安をFAQで先回りして解消し、CTAをLP内に複数（ただし文言は統一）配置することで、どのタイミングでも迷わず予約に進める導線にしている。

## 10. マーケティングリサーチに基づくブラッシュアップ（2026年8月23日）

`/Users/ijiri/Downloads/LP作成マーケティング重要項目リサーチ.pdf`（CXL、Think with Google、Ventureharbour等を出典とするCRO調査資料）を参照し、以下2点を追加対応しました。

| 資料の指摘 | 対応内容 |
|---|---|
| ファーストビューを「終わったように見える」デザイン（false bottom）にしない／続きがあることを視覚的に示唆する（p.5） | FV下部にバウンドするスクロール矢印（`.scroll-cue`）を追加 |
| 社会的証明（証言）の直後・複数箇所にCTAを設置。証言直後のCTAは単独でCVR+68%の報告あり（p.7-8） | 「お客様の声」セクション直後、「FAQ」セクション直後にそれぞれCTAボタンを追加 |

その他、資料の指摘のうち本LPで既に対応済みだった項目：
- CTAボタンの文言をアクション＋ベネフィット型に（「無料体験に予約する」）
- CTAの背景コントラスト確保
- モバイルの表示速度最適化（画像11MB→2.2MB、lazy loading、不要なJS/フレームワークなし）
- 具体的な数字（-7kg、-13kg等）を含む社会的証明の掲載
- フォームを使わずLINE予約に統一し、入力摩擦そのものを排除（EFOの観点で最も摩擦が少ない形）

なお資料内の改善率（CVR+◯◯%等）は業種・母数の異なる個別事例の集計であり、本LPで同じ倍率の効果を保証するものではない旨、資料自体にも明記されています。実際の効果は本LPでのA/Bテスト（8章参照）で検証することを推奨します。
