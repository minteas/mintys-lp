# ミンティーズ LP（体験予約獲得用）

**公開URL**: https://minteas.github.io/mintys-lp/
**リポジトリ**: https://github.com/minteas/mintys-lp （public / GitHub Pages, source: main branch `/`）

安城市・三河安城駅のパーソナルジム「ミンティーズ（Mintea's）」の集客LP。
40代・50代の女性を中心に、体験トレーニング予約のCVを最優先して設計。

情報ソース: `https://gym.mintea.jp`（2026年8月22日時点の公開情報を基に作成）

## 1. ファイル構成

```
mintys-lp/
├── index.html          … LP本体
├── css/style.css        … スタイル（モバイルファースト）
├── js/main.js            … CTA遷移先の一元管理 / CV計測の下地
├── images/                … 実サイトから許諾取得の上ダウンロード・最適化した画像
│   └── raw/               … 元画像（未圧縮）のバックアップ
└── README.md              … 本ファイル
```

## 2. CTAリンクの差し替え方法

`js/main.js` 冒頭の `CONFIG` オブジェクトを書き換えるだけで、
電話・LINE・予約フォームへのリンクがサイト全体に反映されます。

```js
var CONFIG = {
  TEL: "0566-77-7772",
  LINE_URL: "https://line.me/ti/p/@luy1644d",
  FORM_URL: "https://gym.mintea.jp/contact/", // ← 専用フォームができたら差し替え
};
```

## 3. CV計測について

- `data-cta` 属性のついた要素をクリックすると `dataLayer.push({event:"cta_click", ...})` が発火します（GTM未導入でも動作、GTM導入後は自動でタグに拾わせられます）。
- スクロール到達率（25/50/75/100%）も同様に `dataLayer.push({event:"scroll_depth", ...})` されます。
- GTMコンテナIDが決まったら `index.html` の `<!-- GTM PLACEHOLDER -->` 直後に公式スニペットを追加してください（IDが不明なため未設置）。

## 8. 次にABテストすべき項目 3つ

1. **ファーストビューの見出し**：現行の「頑張っているのに変わらないのは、やり方が合っていないだけかもしれません。」（原因の言い換え訴求）と、「40代から、無理なく続けられるボディメイクを。」（ターゲット直球訴求）を比較し、体験予約率への影響を検証する。
2. **体験訴求の出し方**：「体験0円キャンペーン」を最終CTA直前にも大きく再掲するパターンと、現行のように料金セクション内にとどめるパターンを比較する（不安を煽らず自然に後押しできるか）。
3. **コース紹介の並び順**：現行は「3ヶ月集中→ボディメイク→健康改善」の順（集中コースを最優先訴求）。健康改善コース（心理的ハードルが低い月額プラン）を先頭に置くパターンと比較し、どちらがコース詳細への熟読・CTAクリックにつながるかを検証する。

## 9. なぜこのLP構成なら体験予約率が上がると考えたか

1. **「私のことだ」と思わせる悩み描写**：お腹・二の腕・姿勢・股関節など、40〜50代女性が読んだ瞬間に自分ごと化できる具体的な悩みを冒頭で提示し、以降のコンテンツを読み進める動機を作っている。
2. **24時間ジム・自己流を否定しない論理構成**：「今まで頑張ってきたこと」を否定せず「やり方が合っていなかっただけ」と再解釈させることで、心理的な防御（「自分の努力不足を指摘された」という反発）を避けつつ、パーソナル併用の必要性を自然に納得させている。
3. **回数券ではなく目的別プログラムとして提示**：「24回券」ではなく「3ヶ月短期集中ダイエットコース」として見せることで、購入対象を「トレーニング回数」から「その先にある身体の変化」に転換し、価格の心理的ハードルよりも成果イメージを先に想起させている。
4. **実績と根拠に基づく安心設計**：元RIZAP実績トレーナー・生理学/解剖学/栄養学に基づく指導・完全個室・実在するお客様の声など、"追い込み系"ではなく"根拠のある伴走型"という差別化ポジションを一貫して裏付けている。
5. **不安解消と摩擦の最小化**：運動が苦手／食事制限が厳しそう／他の客と会う／持ち物が分からないといった、初めてのパーソナル利用者が体験予約直前に感じる不安をFAQで先回りして解消し、CTAをLP内に複数（ただし文言は統一）配置することで、どのタイミングでも迷わず予約に進める導線にしている。
